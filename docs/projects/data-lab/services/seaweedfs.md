# SeaweedFS

## Why SeaweedFS 

I wanted a service that would place the role of an object store (simulate AWS S3). Originally I planned on using MinIO as it seemed to ba a popular choice . However I subsequently discovered that MinIO had archived their open source project. 
SeaweedFS seemed to be a popular alternative and the SeaweedFS docker container version appeared reasonably straight forward to manage.
Right now, I am only using it as a staging ground for parquet files - it seems to meet my needs.
