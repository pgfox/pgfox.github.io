# Self-Hosted Data Lab

I have built a docker compose network that wire together open source tools/apps that I can use on different projects. It provides functionality such as database, Object storage (S3 compilant), orchestration, SSO, BI tooling, and monitoring.


It runs within one docker compose file on a single machine. I have a 'dev' version of the data lab running on my home network and a 'prod' version running a VPS in the cloud
